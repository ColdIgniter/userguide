# Number Helper

The Number Helper file contains functions that help you work with numeric data in a locale-aware manner.

## Loading this Helper

This helper is loaded using the following code:

```cfm
<cfset helper("number")>
```

## When Things Go Wrong

If the number formatting of Java cannot handle a value provided, for the given locale and options, then an exception of the type `ColdIgniter.Exceptions.BadFunctionCallException` is thrown.

!!! note "Difference from CodeIgniter"
    CodeIgniter formats numbers with the ICU library. ColdIgniter uses the number formatting of the Java version that ColdFusion MX 6.1 runs on (Java 1.4.2). Its locale data is older, so the output can differ for a locale other than `en_US`: the currency symbol, the decimal and grouping separators, the pattern of a negative currency amount, and a locale that Java does not know. Java 1.4.2 also does not know every ISO 4217 currency code (`RSD`, for one). `number_to_currency()` with such a code throws the exception above.

## Available Functions

The following functions are available:

### number_to_size()

`number_to_size(num, precision, locale)`

- `num` (number or string): the number of bytes.
- `precision` (numeric, optional, default `1`): the floating point precision.
- `locale` (string, optional, default `""`): the locale to use for formatting. If `""`, the locale of the request is used.
- Returns the formatted data size string, or `false` if the provided value is not numeric.

Formats numbers as bytes, based on size, and adds the appropriate suffix. Examples:

```cfm
<cfoutput>
#number_to_size(456)# <!--- Returns 456 Bytes --->
#number_to_size(4567)# <!--- Returns 4.5 KB --->
#number_to_size(45678)# <!--- Returns 44.6 KB --->
#number_to_size(456789)# <!--- Returns 446.1 KB --->
#number_to_size(3456789)# <!--- Returns 3.3 MB --->
#number_to_size(12345678912345)# <!--- Returns 11.2 TB --->
</cfoutput>
```

An optional second parameter allows you to set the precision of the result:

```cfm
<cfoutput>#number_to_size(45678, 2)#</cfoutput> <!--- Returns 44.61 KB --->
```

An optional third parameter allows you to specify the locale that should be used when generating the number, and can affect the formatting. If no locale is specified, the locale of the request is used: the one taken from the headers, or the app default:

```cfm
<!--- Generates 11.2 TB --->
<cfoutput>#number_to_size(12345678912345, 1, "en_US")#</cfoutput>
<!--- Generates 11,2 TB --->
<cfoutput>#number_to_size(12345678912345, 1, "fr_FR")#</cfoutput>
```

!!! note
    The text generated by this function is found in the following language file: `Language/<your_lang>/Number.cfm`

### number_to_amount()

`number_to_amount(num, precision, locale)`

- `num` (number or string): the number to format.
- `precision` (numeric, optional, default `0`): the floating point precision.
- `locale` (string, optional, default `""`): the locale to use for formatting. If `""`, the locale of the request is used.
- Returns a human-readable version of the number, or `false` if the provided value is not numeric.

Converts a number into a human-readable version, like **123.4 trillion**, for numbers up to the quadrillions. Examples:

```cfm
<cfoutput>
#number_to_amount(123456)# <!--- Returns 123 thousand --->
#number_to_amount(123456789)# <!--- Returns 123 million --->
#number_to_amount(1234567890123, 2)# <!--- Returns 1.23 trillion --->
#number_to_amount("123,456,789,012", 2)# <!--- Returns 123.46 billion --->
</cfoutput>
```

An optional second parameter allows you to set the precision of the result:

```cfm
<cfoutput>#number_to_amount(45678, 2)#</cfoutput> <!--- Returns 45.68 thousand --->
```

An optional third parameter allows the locale to be specified:

```cfm
<cfoutput>#number_to_amount("123,456,789,012", 2, "de_DE")#</cfoutput> <!--- Returns 123,46 billion --->
```

### number_to_currency()

`number_to_currency(num, currency, locale, fraction)`

- `num` (numeric): the number to format.
- `currency` (string): the currency type, such as `USD` or `EUR`.
- `locale` (string, optional, default `""`): the locale to use for formatting. If `""`, the locale of the request is used.
- `fraction` (numeric, optional, default `0`): the number of fraction digits after the decimal point.
- Returns the number as the appropriate currency for the locale.

Converts a number in common currency formats, like USD, EUR, GBP, and so on:

```cfm
<cfoutput>
#number_to_currency(1234.56, "USD", "en_US", 2)# <!--- Returns $1,234.56 --->
#number_to_currency(1234.56, "EUR", "de_DE", 2)# <!--- Returns 1.234,56 € --->
#number_to_currency(1234.56, "GBP", "en_GB", 2)# <!--- Returns £1,234.56 --->
</cfoutput>
```

If you do not specify a locale, the locale of the request is used.

!!! note "Difference from CodeIgniter"
    The currency must be an ISO 4217 code that Java knows. CodeIgniter prints an unknown code, such as `YEN`, in front of the number. ColdIgniter throws `ColdIgniter.Exceptions.BadFunctionCallException` for it.

### number_to_roman()

`number_to_roman(num)`

- `num` (number or string): the number to convert.
- Returns the roman number converted from the given parameter.

Converts a number into roman:

```cfm
<cfoutput>
#number_to_roman(23)# <!--- Returns XXIII --->
#number_to_roman(324)# <!--- Returns CCCXXIV --->
#number_to_roman(2534)# <!--- Returns MMDXXXIV --->
</cfoutput>
```

This function only handles numbers in the range 1 through 3999.

!!! note "Difference from CodeIgniter"
    CodeIgniter returns `null` for any value outside that range. CFML has no null, so ColdIgniter returns an empty string.
