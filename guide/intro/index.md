# Welcome to ColdIgniter

ColdIgniter is a full-stack web framework for ColdFusion MX 6.1. It is a CFML port of CodeIgniter 4.

It is an application development framework: a toolkit for people who build web sites in CFML. Its goal is to let you develop projects much faster than you could by writing code from scratch, by giving you a set of libraries for common tasks and a simple interface and logical structure to reach them.

ColdIgniter lets you focus on your project by keeping down the amount of code a task needs.

Where possible, ColdIgniter is kept flexible, so you can work the way you want. Core parts can be extended or replaced to make the system work the way you need it to.

In short, ColdIgniter is a framework that tries to give you the tools you need while staying out of the way.

!!! note "Difference from CodeIgniter"
    ColdIgniter is not the original. It follows CodeIgniter 4 as far as ColdFusion MX 6.1 allows: components are `.cfc` files, templates are `.cfm` files, and there is no command line tool and no Composer. [PARITY.md](https://github.com/ColdIgniter/coldigniter/blob/trunk/PARITY.md) in the source shows how much of CodeIgniter 4 is ported.

## Is ColdIgniter Right for You?

ColdIgniter is right for you if:

- You want a framework with a small footprint.
- You want a framework that has a number of features and techniques to make good security practice easy.
- You want a framework whose source code you can find and read without magic.
- You want a framework that needs almost no configuration.
- You want a framework that does not force restrictive coding rules on you.
- You do not want to learn a templating language (although a view parser is available if you want one).
- You like simple solutions over complex ones.
- You need clear documentation.
- You need to build a modern web site on ColdFusion MX 6.1.
