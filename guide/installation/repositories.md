# ColdIgniter Repositories

## coldigniter organization

The ColdIgniter project has its own [GitHub organization](https://github.com/ColdIgniter).

| Repository | Audience | Description |
|---|---|---|
| [coldigniter](https://github.com/ColdIgniter/coldigniter) | developers, contributors | The framework, the starter application (`app/`, `public/`, `writable/`) and its tests |
| [userguide](https://github.com/ColdIgniter/userguide) | anyone | The source of this user guide |
| [website](https://github.com/ColdIgniter/website) | developers | The website of ColdIgniter, written with ColdIgniter |

!!! note "Difference from CodeIgniter"
    CodeIgniter 4 has one repository for development and separate deployment repositories (`framework`, `appstarter`) that are built on release, plus packages on Packagist. ColdIgniter has one repository for the framework and the starter application, and no Composer packages.

The latest version of a repository is the `trunk` branch. It can be cloned, or downloaded as a zip file with the "Code" button of its GitHub page. Releases are listed on the "Releases" page of the repository, when there are any.

See the [Installation](index.md) page for more information.
