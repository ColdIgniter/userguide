# ColdIgniter User Guide

ColdIgniter is a CFML port of [CodeIgniter 4](https://codeigniter.com/). It runs on ColdFusion MX 6.1 and follows CodeIgniter 4 as closely as the language allows: the same folders, the same class names and the same way to write controllers, models, views and routes.

!!! note "This guide is new"
    Only a few pages exist so far. More pages are added as the port grows.

## Where to start

- [Server requirements](intro/requirements.md): what the server needs.
- [Installation](installation/index.md): how to put a site on a server.
- [Several servers](installation/several_servers.md): one application behind a load balancer.
- [Controllers](general/controllers.md): how a request reaches your code.
